RG Prado Appliance Service

2026

Client project · Design & build

A lead-generating website for an owner-operated appliance repair business serving Winnipeg to West St. Paul. The client had been relying on word of mouth and a template site that buried his phone number. The brief was to turn "appliance repair Winnipeg" panic-searches into phone calls.

  • Role: Sole developer and designer. I pitched the project, closed the client with a working MVP at the first meeting, and delivered two rounds of revisions
  • Built: An interactive SVG stove-dial diagnostic in the hero, a 19-photo auto-advancing slideshow with crossfades and blur-fill backdrops, and a lead-capture form wired to Formspree with dynamic email subjects, a honeypot spam trap and a phone fallback if delivery fails
  • Decisions: Vanilla HTML, CSS and JavaScript with no frameworks and no build step, keeping the whole site under 40 KB so it loads instantly on mobile data. Design tokens in CSS custom properties, data-driven config arrays, progressive enhancement, and prefers-reduced-motion respected across every animation
  • Shipped: Deployed to GitHub Pages on a custom domain with Cloudflare Web Analytics

Prospect Finder

2026

Python tool · Google Places API

A command-line tool that finds Winnipeg businesses with no website, or only a Facebook page, and exports them to a spreadsheet. I wrote it to build my own freelance pipeline, and it's how I found my first client.

  • Built: Queries the Google Places API across 11 service categories and 6 Winnipeg neighbourhoods, classifies each result by web presence, and writes a clean CSV with contact details, ratings and review counts
  • Decisions: Used a Places field mask to request only the fields needed, keeping the tool inside the free monthly API allowance, and paced requests to stay within rate limits
  • Result: A qualified prospect list of 126 local businesses
